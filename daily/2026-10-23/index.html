编选说明

这份站点如何选论文，以及它不做什么。

  • 本期由 scripts/daily_update.py 在 GitHub Actions 里自动生成，没有任何人工挑选或改写。
  • 「匹配度」是关键词打分：领域锚点 24 分起，每命中一个领域词 +9，标题里出现 GNSS/TEC/ROTI 等锚点再 +12。它只用于排序。
  • 同一天重复运行会跳过已存在的期号；想重跑请加 --force。
  • 机器初筛不等于推荐。重要结论、数字和适用边界请回到 arXiv 原文核对。
领域相关性 40%是否落在 GNSS 定位、电离层监测、深度学习预测、工程感知四条主线内。
方法增量 25%是否改变问题建模、标签定义、数据使用或工程约束，而不是只换网络/换指标。
证据强度 20%实测/仿真、事件数、站点数、是否留出验证、是否有代码或数据。
连接度 15%与 ROTI–PPP、CDSF-NET、DORIS/ISMR、CORS 完好性等既有工作的可迁移程度。

与你知识库的对应

站点里的「与你工作的连接」不是泛泛的启发，而是尽量指向你已有的数据与问题：ROTI 与 PPP 恢复时序、短弧/连续弧龄、CDSF-NET 的条件物理融合、DORIS-ROTI 的互补观测、ISMR 高频闪烁、CORS 网络一致性。

更新方式

页面由 scripts/build_site.py 从 data/editions/*.json 生成，一天一期。每天北京时间 06:00 由 GitHub Actions 跑 scripts/daily_update.py，抓取 arXiv 新论文、按关键词初筛成当期并自动发布；这类条目标注「机器初筛」，中文解读需要人工确认后再改写对应期号的数据文件。
